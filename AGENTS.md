# AGENTS.md

Канонический гайд по проекту — **[CLAUDE.md](./CLAUDE.md)**. Читай его целиком:
там архитектура, команды, тестирование сервера, CI и критические инварианты.

Самое важное в двух словах (детали — в CLAUDE.md):

- **MeshVoice** — Expo/RN рация + мото-соцсеть, самохостируемый Node-бэкенд. UI и
  общение с владельцем — на **русском**.
- Перед коммитом: `npx tsc --noEmit`. Сервер после правок `src/`:
  `cd server && npm run build` (Node **22.5+**, `node:sqlite`) и **перезапуск**
  процесса на :3000.
- Адрес бэкенда — только `lib/config.ts` (`BACKEND_URL`), UI-редактирования IP нет.
- `applicationId` залочен на `com.anonymous.myapp` — не менять.
- Микрофон захватывается только при входе в комнату; `three.tsx` — TAB-отступы.
- Чистый JS/TS не требует пересборки APK; правки `app.json`/нативного → коммит
  с тегом `[BUILD]`.
- Маршруты `/rides/history|active` — ДО `/rides/:id`. Тесты сервера — на
  изолированной базе (`DB_PATH`+`PORT=3999`), не трогая боевую :3000.
